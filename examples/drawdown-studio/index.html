Drawdown

A weaver does not draw cloth. They write down three things — which shaft each warp thread is heddled on, which shafts each treadle lifts, and the order the treadles are pressed — and the cloth is whatever those three produce. Change any square below and the cloth changes with it.

At the loom

Reading the four grids

Threading, along the top

One column for every warp end on the loom, running left to right as the threads run through the heddles. The filled square in a column is the shaft that end is threaded on. Shaft one is the row nearest the cloth; shaft eight is furthest back.

Tie-up, at the corner

One column for every treadle, one row for every shaft. A filled square means that treadle is corded to that shaft, so pressing it lifts that shaft and every warp end threaded on it. This is the part a weaver changes least often: retying a loom takes an afternoon underneath it.

Treadling, down the side

One row for every pick of weft, read downward in the order they are woven. The filled square says which treadle is pressed. A walking treadling — one, two, three, four, and back to one — is what turns a twill tie-up into a diagonal.

The drawdown itself

Nothing is entered here. A square shows warp where the pick’s treadle lifted the shaft that end is threaded on, and weft where it did not. Every float, every diagonal, and every diamond in the cloth is a consequence of the other three grids, which is the whole reason the notation is worth learning.

Demonstration document. The interlacement is computed, not drawn: each square of the cloth is the result of testing the pick’s treadle against the end’s shaft, so the drawdown cannot disagree with the draft above it. Plain weave, 2/2 twill, herringbone, goose eye, and log cabin are standard structures from the handweaving repertoire rather than invented patterns. The dye names are the historical sources — indigo, madder, weld, walnut, iron — and the colours are approximations of them, not measured samples.
