# Practical Exercises

This directory holds the calibration project's required practical exercises, kept structurally separate from `examples/` (the round-8 Perigee Mission Control build, which predates the revised process) and from the research documents at the repo root. Each exercise subdirectory is built using the **revised** process in `ANTI_VIBE_CODING_UI.md` — real product brief, structurally different creative directions anchored to real named references, "No Recipe Without Reason" applied to any reference drawn on, asset-strategy classification, rendered comparison, and independent blind critique before any completion claim.

## Why the 4-variant exercise was assigned to "dense professional application"

`CLAUDE_DESIGN_DEFAULTS.md` flags two hypotheses as explicitly unconfirmed, both specific to this category: **Default 7** (a cool, restrained teal/cyan accent reached for reflexively on "serious" products) and **Default 8** (dark-native theming as the reflexive answer to "dense/professional"). Both were observed exactly once, on Perigee Mission Control, which is not enough evidence to call either a real pattern rather than a correct one-off decision for that specific product. The calibration brief's own required instrument for this — 4 structurally distinct versions of one brief (authored minimalism, information-dense utilitarian, warm humanist, expressive/experimental) — is the direct test: if a warm, light-themed variant of a *different* dense professional brief still drifts toward cool/dark without a stated reason, that confirms a real default. If it doesn't, Defaults 7 and 8 get removed from `CLAUDE_DESIGN_DEFAULTS.md` rather than kept out of caution. See `dispatch-console/CREATIVE_DIRECTION.md` for the full brief and the four directions.
