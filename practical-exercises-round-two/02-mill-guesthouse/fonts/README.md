# Fonts — 02 Bellman's Mill

Self-hosted woff2, fetched from the Google Fonts CSS API and subset to latin and latin-ext only.
No font is loaded from a third-party host at runtime.

| Family | Licence | Loaded by |
|---|---|---|
| Schibsted Grotesk | SIL Open Font License 1.1 | `fonts.css` — the only family on `index.html` and `stay.html` |
| Literata | SIL Open Font License 1.1 | `study.css` only |
| Zilla Slab | SIL Open Font License 1.1 | `study.css` only |

Literata and Zilla Slab are kept because they are two of the three directions in
`../../evaluation/02-studies/typography.html`. Deleting them would leave the specimen test
unrenderable, which would make the recorded decision unverifiable. They are not referenced by either
page of the site.

Weights shipped: 400, 500, 700 for Schibsted Grotesk; 400 and 600 plus 400 italic for Literata;
400, 500, 700 for Zilla Slab.
